# 附录 A：全课程符号与默认约定

[← 课程主页](../../README.md) | [English](../en/appendix-a-notation.md) | [第 1 章](01-what-is-ml.md)

> 本页是全课程的唯一符号标准。正文若采用其他论文或教材的写法，必须先说明转换关系。

## A.1 字体、大小写和索引

| 类型 | 课程写法 | 例子 | 含义 |
|---|---|---|---|
| 标量 | 小写 | $b,\eta,\lambda$ | 一个数：偏置、学习率、正则强度 |
| 向量 | 小写 | $x,w,y$ | 有顺序的一列数 |
| 矩阵 | 大写 | $X,W,A$ | 行列组成的二维数组 |
| 集合 | 花体/大写 | $\mathcal D,\mathcal X$ | 数据集、输入空间 |
| 随机变量 | 依语境说明 | $Y$ | 尚未观测的随机量 |
| 观测值 | 小写 | $y$ | 随机变量的一次具体结果 |

数学索引从 1 开始，Python/NumPy 索引从 0 开始。因此数学中的 $X_{32}$ 在 Python 中写
`X[2, 1]`。

## A.2 样本与特征：最重要的约定

设有 $m$ 个样本、每个样本 $d$ 个特征：

$$X\in\mathbb R^{m\times d},\qquad y\in\mathbb R^m.$$

| 符号 | 固定含义 | 房屋数据例子 |
|---|---|---|
| $x$ | 泛指一个样本的特征向量 | `[面积, 房龄, 电梯]` |
| $x^{(i)}$ | 第 $i$ 个样本向量 | 第 3 套房的全部特征 |
| $x_j$ | 泛指向量 $x$ 的第 $j$ 个特征 | 房龄 |
| $x_j^{(i)}$ | 第 $i$ 个样本的第 $j$ 个特征 | 第 3 套房的房龄 |
| $X_{ij}$ | 矩阵 $X$ 第 $i$ 行第 $j$ 列 | 与 $x_j^{(i)}$ 相同 |
| $y^{(i)}$ | 第 $i$ 个样本的真实标签 | 第 3 套房真实租金 |
| $\hat y^{(i)}$ | 第 $i$ 个样本的预测 | 模型预测的第 3 套房租金 |

本课程**不使用** $x_i$ 表示第 $i$ 个样本，避免和“第 $i$ 个特征”混淆。引用其他资料时若
看到 $x_i$ 表示样本，要先在脑中换成 $x^{(i)}$。

## A.3 常见计数与形状

| 符号 | 默认含义 |
|---|---|
| $m$ | 样本数 |
| $d$ | 输入特征维度 |
| $K$ | 类别数 |
| $B$ | mini-batch 大小 |
| $T$ | 序列长度/token 数 |
| $D$ | embedding/hidden 维度，出现时会与特征维度 $d$ 明确区分 |
| $L$ | 网络层数或单样本损失，按上下文明确说明 |

LLM 隐状态 $H\in\mathbb R^{B\times T\times D}$：$B$ 个序列，每个序列 $T$ 个 token，每个
token 用 $D$ 维向量表示。

## A.4 模型与优化

| 符号 | 含义 |
|---|---|
| $f_\theta$ | 参数为 $\theta$ 的模型 |
| $\theta$ | 全部可学习参数的统称 |
| $w,b$ | 权重与偏置 |
| $\ell(\hat y,y)$ | 一个样本的损失 |
| $J(\theta)$ | 全体样本的训练目标，可能含正则项 |
| $\eta$ | 学习率 |
| $\lambda$ | 正则化强度 |
| $\nabla_\theta J$ | $J$ 对全部参数的梯度 |
| $\hat\theta$ | 估计/训练得到的参数 |
| $\theta^*$ | 理论最优参数 |

帽子通常表示“估计”，星号通常表示“最优”。二者不自动相等：有限数据和有限优化只能得到估计。

## A.5 概率与统计

| 符号 | 含义 |
|---|---|
| $p(x)$ | 概率质量或密度；连续变量的密度值本身可大于 1 |
| $p(y\mid x)$ | 已知 $x$ 时 $y$ 的条件分布 |
| $\mathbb E[X]$ | 随机变量 $X$ 的期望 |
| $\mathrm{Var}(X)$ | 方差 |
| $\mathrm{Cov}(X,Y)$ | 协方差 |
| $X\sim\mathcal N(\mu,\sigma^2)$ | $X$ 服从均值 $\mu$、方差 $\sigma^2$ 的正态分布 |
| $\perp$ | 独立/正交，必须由语境说明 |

数据矩阵也记作 $X$，随机变量有时也用大写 $X$。当两者同节出现时，本课程会明确写“数据矩阵
$X$”或“随机变量 $Z$”，避免仅靠字体猜测。

## A.6 分类标签约定

- 二分类默认 $y\in\{0,1\}$，适合概率与交叉熵；
- SVM/间隔推导可能改用 $y\in\{-1,+1\}$，章节开头必须声明；
- 多分类类别索引为 $y\in\{1,\ldots,K\}$；
- one-hot 标签记为向量 $\mathbf y\in\{0,1\}^K$，仅正确类位置为 1。

## A.7 常用运算

| 符号 | 读法/意义 |
|---|---|
| $a^Tb$ | 点积；结果是标量 |
| $AB$ | 矩阵乘法，不是逐元素相乘 |
| $A\odot B$ | 逐元素乘法 |
| $\|x\|_1,\|x\|_2$ | 一范数、二范数 |
| $I$ | 单位矩阵 |
| $\sum_i$ | 对索引 $i$ 求和 |
| $\prod_i$ | 对索引 $i$ 求乘积 |
| $\arg\min_\theta J$ | 返回使目标最小的参数 |
| $\min_\theta J$ | 返回最小目标值 |
| $\propto$ | 正比于 |
| $\approx$ | 近似相等 |

## A.8 默认的数据与实验规则

除非章节另有说明，默认：

1. 监督学习数据写作 $\mathcal D=\{(x^{(i)},y^{(i)})\}_{i=1}^m$；
2. 样本按行、特征按列；
3. 预处理参数只在训练集拟合，再原样应用到验证/测试集；
4. 验证集选择模型与超参数，测试集只做最终验收；
5. 报告随机种子、数据划分、均值与波动，不只报告最好一次；
6. 所有矩阵公式尽量标注输入和输出形状；
7. 概率、因果、统计显著与业务重要性不得互相替代。

## A.9 读公式的固定检查法

看到新公式，依次问：

1. 每个符号定义了吗？是标量、向量还是矩阵？
2. 每个量的形状是什么？运算合法吗？
3. 求和索引遍历样本、特征还是类别？
4. 哪些量已知，哪些量要学习？
5. 等号是严格恒等、定义、近似还是优化结果？
6. 公式依赖什么概率或数据假设？
7. 对应代码会在哪里广播、溢出或泄漏？

如果一节正文无法回答这七问，应视为讲解尚未完成，而不是读者“数学不好”。
