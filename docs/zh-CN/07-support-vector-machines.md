## 从第 6 章自然走到这里

kNN 保存所有样本并在预测时查询。能否训练时找出少数真正决定边界的关键样本，预测时只依赖
它们？支持向量机（SVM）给出的答案是：选择不仅能分开两类、而且离两类都尽可能远的边界。

## 7.1 为什么“分对”还不够？

先看一个不带公式的例子。我们要用“邮件长度”和“可疑词比例”判断垃圾邮件，训练集上下面三条线
都能把两类完全分开：

- 线 A 紧贴正常邮件；一封邮件多出几个可疑词，它就会被翻到错误一侧；
- 线 B 紧贴垃圾邮件，同样脆弱；
- 线 C 位于两类中间，离最近的两边样本都比较远。

三条线的训练准确率同为 100%，但现实中的特征会有测量误差，新邮件也不会与训练邮件完全相同。
因此我们不只要问“训练样本分对了吗”，还要问“边界周围留下了多大的安全缓冲”。这个缓冲就是
**间隔（margin）**。SVM 的核心偏好可以先记成一句话：

> 在能够分开两类的边界中，优先选择离两类最近样本都更远的那一条。

这回答了“为什么需要 SVM”：仅凭训练准确率无法区分许多候选边界，最大间隔给出了一个偏好，
使边界对小扰动更稳健。它不是保证永不出错，而是一种控制模型复杂度、改善泛化的原则。

<details><summary>苏格拉底追问：既然三条线都分对了，为什么不能随便选一条？</summary>
训练集只是有限样本。紧贴某个点的边界可能是在迁就偶然噪声；新样本轻微移动就会越界。我们需要
一个不只描述“现在是否分对”，还描述“离出错还有多远”的标准。
</details>

## 7.2 间隔到底是什么？

现在再把“安全缓冲”翻译成数学。设标签 $y\in\{-1,+1\}$，模型分数
$f(x)=w^Tx+b$； $f(x)=0$ 是决策边界。把标签乘进分数，得到 signed score
$y^{(i)}f(x^{(i)})$：它为负表示分错，为正表示分对，越大表示位于正确一侧越深。

- functional margin： $y^{(i)}f(x^{(i)})$；
- geometric margin： $y^{(i)}f(x^{(i)})/\|w\|_2$。

为什么还要除以 $\|w\|_2$？把 $w,b$ 同时放大 10 倍不会移动边界，却会把 functional margin
放大 10 倍；它不是实际距离。除以 $\|w\|_2$ 后缩放被抵消，才得到点到超平面的有符号距离。

为了去掉任意缩放，SVM 约定最近样本满足 functional margin 为 1。此时最大化几何间隔等价于
最小化 $\|w\|^2/2$。这里的“1”只是规范化约定，不是数据天然带有的距离单位。

![SVM间隔、决策边界与支持向量](../assets/svm-margin-support-vectors.png)

图中的蓝点和橙点代表两个类别，横纵轴是两个输入特征。中间的黑色实线满足 $f(x)=0$，是模型
真正使用的分类边界；两条灰色虚线分别满足 $f(x)=+1$ 与 $f(x)=-1$，两线之间形成间隔。黑圈
标出了最靠近边界的**支持向量**，可以把两条虚线理解为由这些点“撑住”。移动远处的样本通常
不会改变黑线，而移动支持向量则可能改变间隔宽度或边界位置。

因此，支持向量是“决定最优边界的关键样本”，不等于异常点，也不一定是最有代表性的样本。

## 7.3 硬间隔：理想但脆弱

线性可分时：

$$\min_{w,b}\frac12\|w\|_2^2
\quad\text{s.t.}\quad y^{(i)}(w^Tx^{(i)}+b)\ge1,\ \forall i.$$

两条间隔线为 $w^Tx+b=\pm1$，总宽度为 $2/\|w\|$。一个错标点就可能让硬间隔无解，因此
真实数据通常使用软间隔。

## 7.4 软间隔、hinge loss 与 $C$

引入松弛变量 $\xi_i\ge0$：

$$\min_{w,b,\xi}\frac12\|w\|^2+C\sum_i\xi_i,$$

$$y^{(i)}(w^Tx^{(i)}+b)\ge1-\xi_i.$$

消去 $\xi$ 可得到 hinge loss：

$$\ell=\max(0,1-yf(x)).$$

![hinge loss不仅惩罚分错，也惩罚间隔不足](../assets/hinge-loss.png)

图中横轴是 signed margin $yf(x)$，纵轴是单个样本的 hinge loss。折线的三个区间对应三种状态：

- 横轴小于 0：样本分错，越错越远，损失越大；
- 横轴在 0 到 1：类别虽然分对了，但仍落在安全带内，所以损失仍为正；
- 横轴大于等于 1：不仅分对，而且到达间隔外，损失变为 0；
- 折线在 1 处有尖角，因此这里用的是次梯度，而不是处处普通可导的梯度。

这正体现 SVM 与“只数错几个”的区别：正确但离边界太近，也被视为有风险。目标可写成

$$J(w,b)=\frac12\|w\|^2+C\sum_i\max(0,1-y^{(i)}f(x^{(i)})).$$

![C控制间隔宽度与训练违例的取舍](../assets/svm-c-tradeoff.png)

两个子图使用同一批样本，黑色实线表示分类边界，灰色虚线表示间隔边界。
左图使用较小 $C$，模型愿意容忍少数违例来换取更宽、更平滑的安全带；右图使用较大 $C$，
模型为避免训练违例会更努力绕开个别点，间隔可能收窄。图只展示典型趋势，实际宽度还受数据和
特征缩放影响。

- $C$ 大：训练违例代价高，边界更努力照顾每个点，可能过拟合；
- $C$ 小：允许更多违例以换更宽间隔，正则更强，可能欠拟合。

不同库可能用求和或平均 loss，因此同名 $C$ 的数值尺度不能脱离实现约定比较。

## 7.5 从零实现线性 SVM

若 $y^{(i)}f(x^{(i)})<1$，单样本对 $w$ 的次梯度含 $-Cy^{(i)}x^{(i)}$；否则只有 $L_2$
项。0 点不可导，但次梯度优化仍可进行。

```python
margin = y * (X @ w + b)
active = margin < 1
dw = w - C * X[active].T @ y[active] / m
db = -C * y[active].sum() / m
w -= learning_rate * dw
b -= learning_rate * db
```

运行：

```bash
python code/chapter07/support_vector_machine.py
python code/chapter07/course_lab.py
```

`course_lab.py` 逐步打印三个 margin 的 hinge loss、一次原始问题更新，以及本章后面两点对偶例子的
Gram 矩阵、 $\alpha$、 $w$ 和 margin；主脚本继续负责完整数据与图片。

固定输出：

```text
scratch_test_accuracy=0.952
sklearn_test_accuracy=0.952
```

教学实现用全批量次梯度；工业库会采用更成熟的坐标下降、SMO 或线性优化器。

## 7.6 为什么需要对偶问题？

到目前为止，我们只能在线性边界中优化。若想得到弯曲边界，一个直接想法是先把 $x$ 映射成
更丰富的特征 $\phi(x)$；但高维甚至无限维特征可能根本无法显式构造。对偶问题的价值不是“把
同一道题写复杂”，而是把训练和预测改写成只依赖**样本两两点积**的形式。这样下一节就能把
点积替换为核函数，在不显式写出 $\phi(x)$ 的情况下使用高维特征。

给每个约束引入 $\alpha_i\ge0$，硬间隔 Lagrangian 为

$$\mathcal L=\frac12\|w\|^2-
\sum_i\alpha_i[y^{(i)}(w^Tx^{(i)}+b)-1].$$

对 $w,b$ 令导数为 0：

$$w=\sum_i\alpha_i y^{(i)}x^{(i)},\qquad \sum_i\alpha_i y^{(i)}=0.$$

代回得到对偶：

$$\max_\alpha\sum_i\alpha_i-\frac12\sum_{i,j}
\alpha_i\alpha_jy^{(i)}y^{(j)}x^{(i)T}x^{(j)},$$

满足 $\alpha_i\ge0$；软间隔还有限制 $0\le\alpha_i\le C$。关键发现是训练样本只通过点积
$x^{(i)T}x^{(j)}$ 出现，因此可换成核 $K(x^{(i)},x^{(j)})$。

### 两个点，把对偶变量算成具体数字

取一维样本 $x^{(1)}=-1,y^{(1)}=-1$ 和 $x^{(2)}=1,y^{(2)}=1$。点积组成

```math
K=XX^T=\begin{bmatrix}1&-1\\-1&1\end{bmatrix}.
```

等式约束 $\alpha_1y^{(1)}+\alpha_2y^{(2)}=0$ 要求 $\alpha_1=\alpha_2=a$。把它代入硬间隔
对偶目标可得 $W(a)=2a-2a^2$，令导数 $2-4a=0$，所以 $a=0.5$。再代回

$$w=\sum_i\alpha_i y^{(i)}x^{(i)}=1,\qquad b=0.$$

两个点的 signed margin 都是 1，因此它们都恰好撑在间隔边界上，也都是支持向量。这个极小例子
说明了 $\alpha$ 不是抽象装饰：它记录每个训练点对最终边界的贡献。真实数据再由 SMO 数值求解更多
$\alpha_i$，核方法则把上面的点积矩阵换成核矩阵。

KKT 互补条件说明多数非支持向量 $\alpha_i=0$；预测为

$$f(x)=\sum_{i\in SV}\alpha_i y^{(i)}K(x^{(i)},x)+b.$$

## 7.7 SMO 是什么？

Sequential Minimal Optimization 每次只更新两个 $\alpha$，因为约束
$\sum_i\alpha_i y^{(i)}=0$ 使单独更新一个变量不可行。它在可行区间内解析求解这两个变量，
重复直到 KKT 条件近似满足。初学者应理解更新对象与约束原因，不必立刻背完整工程启发式。

## 7.8 核 SVM：弯曲边界来自隐式特征空间

![RBF核SVM在月牙数据上的非线性边界](../assets/kernel-svm-boundary.png)

图中的蓝点和橙点形成两个月牙类别，黑色曲线是 $f(x)=0$，曲线两侧对应模型预测的类别；
带黑圈的点是支持向量；背景颜色表示 decision score 的正负与大小，不是已经校准的概率。
线性模型无法用一条直线把两个月牙分开，而 RBF 核通过相似度让边界随局部数据弯曲。

输入空间的曲线边界，在隐式 $\phi(x)$ 空间仍对应线性超平面。RBF SVM 有两个关键超参数：

- $C$：违例代价；
- $\gamma$：单个样本影响范围，太大产生局部小岛，太小过度平滑。

二者必须在 pipeline 内联合交叉验证，标准化也必须在每个训练折内部拟合。

## 7.9 与逻辑回归、kNN 怎样选择？

| 方法 | 优势 | 局限 |
|---|---|---|
| 逻辑回归 | 概率、线性可解释、大规模友好 | 原始空间线性 |
| kNN | 局部灵活、训练轻 | 预测慢、高维距离困难 |
| 线性 SVM | 最大间隔、高维稀疏常强 | 原生分数不是概率 |
| 核 SVM | 中小数据非线性强 | 训练/预测随样本量增长 |

SVM 输出 decision score，不自动等于概率。Platt scaling 等校准必须用独立验证数据，不能把
score 经 sigmoid 就宣称为可靠概率。

## 7.10 复杂度、系统成本与失败诊断

核 SVM 需要 Gram 矩阵，内存可达 $O(m^2)$，训练通常超线性甚至更高；支持向量越多，预测越慢。
线性 SVM 更适合大规模稀疏文本。

| 症状 | 原因 | 修复 |
|---|---|---|
| 全预测多数类 | 不平衡、 $C$ 不当 | class weight、指标、阈值 |
| RBF 边界碎裂 | $\gamma/C$ 太大 | 交叉验证、更多数据、缩放 |
| 训练极慢 | 样本太多/支持向量多 | 线性模型、近似核、采样 |
| 概率不可靠 | score 未校准 | 独立校准集、Brier/log loss |

系统选型不能只看准确率：还要记录支持向量数量、模型文件大小、单样本与批量 p95 延迟、峰值内存
和重新训练时间。同样的测试分数下，支持向量更少的核模型通常推理更便宜。

## 7.11 与现代 AI 的联系：margin、排序与 embedding 探针

### 对比学习：共享“拉开正负”的思想，但损失并不等同

经典 contrastive loss、triplet loss 常显式要求负样本至少远离一个 margin；现代 InfoNCE 则用
softmax 对比许多正负对。它们与 SVM 都在塑造相对间隔，但 InfoNCE 不是把 hinge loss 换个名字。
学习这种联系是为了迁移“大间隔”直觉，而不是声称现代大模型内部在训练 SVM。

### 推荐与搜索排序：关心顺序，不一定关心校准概率

pairwise ranking 可要求正样本得分至少比负样本高一个间隔，例如
$\max(0,1-s(x^+)+s(x^-))$。这与 hinge loss 同族，适合“谁排在前面”比“概率是多少”更重要的
场景。若后续需要出价或风险决策，仍要额外进行概率校准。

### LLM 与 embedding：线性 SVM 是便宜而有力的探针

冻结语言模型或视觉模型的 embedding，只训练线性 SVM，可检验某类信息能否被线性读出，也可
作为小样本文本分类、安全路由和异常筛查基线。但“可被探针读出”只说明表示中存在相关信息，
不能证明生成模型在回答时因果性地使用了它。

### 核近似：让非线性思想进入更大数据

随机 Fourier features、Nyström 等方法把核近似成有限维显式特征，再交给线性学习器，从而降低
完整 Gram 矩阵的成本。这延续了“先改变表示，再做线性分隔”的主线。

## 7.12 苏格拉底导师

<details><summary>正确分类的点为什么仍可能有 hinge loss？</summary>
因为 SVM 不只要求符号正确，还要求 signed margin 至少为 1。
</details>

<details><summary>支持向量是否一定是离群点？</summary>
不是。它们是位于/违反间隔、对最优边界有非零对偶权重的关键点。
</details>

<details><summary>为什么把 $w,b$ 同时乘 10，分类边界不变，functional margin 却改变？</summary>
边界由 $w^Tx+b=0$ 的零点集合决定，同乘正常数不改变零点；但函数值被放大。几何间隔除以
$\|w\|$，消除了这种任意缩放。
</details>

<details><summary>$C$ 很大是否一定得到更宽的间隔？</summary>
不是。大 $C$ 更重罚训练违例，模型可能牺牲间隔宽度去照顾个别样本；小 $C$ 才对应更强正则和
对违例更高容忍。具体边界还取决于数据与特征尺度。
</details>

<details><summary>用了 RBF 核以后，为什么还必须标准化？</summary>
RBF 直接依赖欧氏距离。未缩放时大单位特征会主宰距离， $\gamma$ 的含义也随单位改变。
</details>

<details><summary>SVM decision score 经过 sigmoid 就是概率吗？</summary>
不是。任意 sigmoid 变换不自动校准；Platt scaling 或 isotonic regression 必须使用独立数据拟合，
并通过校准曲线、Brier score 或 log loss 验证。
</details>

## 7.14 面试八股

- **SVM 的核心思想？** 在控制训练违例的同时最大化几何间隔，提高对小扰动的稳健性。
- **支持向量是什么？** 位于间隔边界内或违反间隔、具有非零对偶系数并决定边界的样本。
- **硬间隔与软间隔？** 硬间隔不容许违例；软间隔用 $C$ 权衡间隔宽度和训练违例。
- **参数 $C$ 越大，正则越强吗？** 相反；大 $C$ 更重罚违例，等价于相对更弱的正则约束。
- **hinge loss 有什么特点？** $\max(0,1-yf(x))$；分对但间隔不足仍受罚，超过单位间隔损失为 0。
- **为什么转成对偶？** 数据只通过点积出现，可使用核技巧；解还可由支持向量展开。
- **SMO 为什么一次更新两个 $\alpha$？** 单独改变一个变量会破坏 $\sum_i\alpha_i y^{(i)}=0$。
- **RBF 的 $\gamma$ 怎样影响边界？** 大 $\gamma$ 影响范围窄、边界更局部；小 $\gamma$ 更平滑。
- **SVM 输出是概率吗？** 原生是 decision score；需要独立校准，且校准会增加计算和数据需求。
- **核 SVM 什么时候不合适？** 样本极大、内存/延迟严格或支持向量很多时，优先线性模型或核近似。
