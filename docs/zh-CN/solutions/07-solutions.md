# 第 7 章提示与参考答案

[← 第 7 章](../07-support-vector-machines.md) | [English](../../en/solutions/07-solutions.md)

1. **几何间隔**：点到超平面距离为 $|w^Tx+b|/\|w\|$；乘标签统一两侧符号。规范化最近点
   functional margin 为 1 后，最大间隔等价于最小化 $\|w\|^2/2$。若未固定尺度，放大 $w,b$
   就能任意放大 functional margin，优化问题没有意义。
2. **hinge 分段**： $yf<0$ 表示分错且损失大于 1； $0<yf<1$ 虽分对仍位于间隔内； $yf>1$
   损失为 0。 $yf=1$ 处不可导，可使用次梯度集合中的合法值。
3. **关于 $C,\gamma$ 的热图**：标准化和拟合必须在每个训练折内；选择验证均值并报告方差，测试集只验收。
   若准确率相近，可结合支持向量数、训练时间和边界稳定性选择更便宜的模型。
4. **删除点**：删除 $\alpha=0$ 点通常不改对偶展开；删除支持向量可能改边界，但数值容差下需
   重训验证，不能只修改保存后的展开式就宣称结论。
5. **校准**：decision score 只提供相对次序；用独立数据拟合 Platt/isotonic，并比较 Brier、
   log loss 与校准图。校准集过小时 isotonic 更易过拟合。
6. **embedding 对照**：三种模型必须使用同一训练/验证/测试划分和表示。逻辑回归便于概率解释，
   线性 SVM 常是高维小样本强基线，kNN 无须拟合线性边界但查询成本随样本增长。
