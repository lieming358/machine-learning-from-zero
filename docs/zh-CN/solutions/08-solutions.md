# 第 8 章提示与参考答案

[← 第 8 章](../08-trees-and-ensembles.md) | [English](../../en/solutions/08-solutions.md)

1. **不纯度**：先分别计算左右节点的类别比例，再按子节点样本量加权；不能直接平均两个节点。
   同时报告父节点不纯度，信息增益才是 $I(parent)-I(split)$。
2. **两层树**：递归调用树桩搜索，但必须增加最大深度、纯节点、最小叶样本与空子节点保护；每个
   叶子保存类别计数或比例，并用独立测试样本验证路径。
3. **过拟合曲线**：深度增加时训练分数通常单调不降，验证分数可能先升后降。深度应在验证集或
   交叉验证上选择；测试集只在流程冻结后使用一次。
4. **随机森林消融**：固定树深、数据划分与随机种子集合，分别改变 bootstrap、`max_features`
   和树数。若树间错误相关性下降且单树尚有能力，平均的方差收益通常更明显。
5. **Boosting 消融**：小学习率通常需要更多树；比较完整验证曲线、early stopping 轮次、训练
   时间和模型大小，不能只从测试集挑最高点。
6. **重要性审计**：唯一 ID 可被深树记忆并获得高 impurity importance；相关特征会分摊或替代
   重要性。按时间/主体切分、删除特征重训和 permutation 对照比单张 SHAP 图更有说服力。
7. **LLM 路由设计**：特征只能使用决策时可获得的信息，如输入长度、领域、风险分数和队列负载；
   标签可由质量—成本效用定义。必须分别监控误送小模型的质量损失、误送大模型的成本、p95 延迟
   与分布漂移，并保留安全兜底路径。
